## 业务闭环

争议受理 → 账单冻结 → 合同与用量举证 → 税务复核 → 金额授权 → 财务批准 → 客户通知 → 审计留痕。

## 服务端门禁

- 身份、账单冻结、合同权益、用量对账和税务影响必须完成校验。
- 贷项金额必须有效且处于审批权限内，并取得财务批准。
- 经办人与审批人必须分离，审计材料必须完整。
- 原支付关联、标准原因码和客户通知作为可追踪复核事项。

## 接口

`POST /api/enterprise/billing/dispute-credit-authorization`

接口返回 `AUTHORIZE`、`REVIEW` 或 `BLOCKED`，以及可解释的阻断原因与行动清单，适合接入账单、应收和客服工作台。外部支付、税控系统仅预留适配器，由使用方自行配置。
